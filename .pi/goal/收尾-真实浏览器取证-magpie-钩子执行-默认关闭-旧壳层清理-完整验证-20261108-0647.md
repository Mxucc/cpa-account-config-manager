# Goal

完成本次会话剩余的四项收尾工作，使新供应商域与界面达到可交付状态，并留下可复现的证据。

## 1. 真实浏览器取证

用本机 Playwright 1.58 在真实 Chromium 中打开构建后的单文件界面，配合一个同源 mock 供应商 API 完成登录并走查各视图。

交付物：仓库内可复用的 `web/scripts/mock-provider-ui.mjs` 与 `web/scripts/capture-evidence.py`；`.web-builder/evidence/sprint-5/` 下的 1440×900 与 390×844 截图（总览、账号、供应商、供应商详情、额度、用量，另加账号抽屉），以及记录横向溢出与 console 错误的 `visual-report.json` 和结论文本。

## 2. Magpie 插件钩子执行（默认关闭、可降级）

在已有“清单导入”之上增加一个可选的 Bun sidecar：仅执行插件的登录、模型目录与额度三个钩子，不接管请求路由；默认关闭，Bun 缺失或插件异常时明确降级，不影响原生供应商。

交付物：新的 Go 包（JSON-line RPC 客户端 + 超时/输出上限/并发上限/可执行文件白名单/崩溃隔离）、配套 Node 启动脚本、一个默认 `false` 的设置项、以及覆盖成功/超时/崩溃/超大输出/Bun 缺失/开关关闭六条路径的测试（使用自写夹具插件，不联网）。

## 3. 旧壳层清理

删除旧顶层壳层（`web/src/App.tsx` 及其专属样式与测试），但保留 Codex / OpenCode / Cline Pass 三个旧工作区组件作为供应商详情的「兼容（旧界面）」页签；仍被新页面使用的弹窗与面板迁到新调用点或确认已被覆盖后删除。

## 4. 完整验证与交付记录

跑完整 `make verify` 与 `make package`，把日志、包信息与最终结论写入 `.web-builder/evidence/`。

# Acceptance criteria

1. `go test ./...` 与 `go test -race ./...` 通过；`go vet ./...` 无输出；`gofmt -l` 在全部 Go 文件上为空。
2. `cd web && npx tsc --noEmit -p tsconfig.json` 无错误；`npm test -- --run --pool=forks --maxWorkers=1` 全部通过；`npm run build` 成功。
3. `make verify` 退出码为 0，日志保存在 `.web-builder/evidence/verify.log`。
4. `.web-builder/evidence/sprint-5/` 中至少有 12 张非空白截图（每个视口 6 个视图，另有账号抽屉）；`visual-report.json` 里每条记录 `overflows` 为 false 且 `console` 为空数组；脚本退出码为 0。
5. 截图中，夹具里 `used_percent: null` 的额度窗口显示为“未上报”，不出现 0% 或满格进度条；钱包账号显示余额而非进度条。
6. 设置项 `magpie_hook_execution` 默认关闭；关闭时 `/providers/accounts` 的返回与当前实现逐字段一致（有回归测试证明），导入项 `hook_execution` 仍为 false。
7. 开启开关且 Bun 可用时，夹具插件的模型数与额度窗口出现在 `/providers/accounts`；Bun 不可用时接口返回可读的降级原因，且原生供应商的账号与额度不受影响。
8. `web/src/App.tsx` 已删除；构建后页面中供应商详情的「兼容（旧界面）」页签仍能打开对应旧工作区（有测试或截图证明）。
9. `make package` 产出安装包，`dist/release/` 内含与包一致的 `checksums.txt`；版本号与校验和记录在证据报告中。
10. `.web-builder/evidence/report.md` 的每条结论都能对应到日志、截图或测试命令；未验证项如实标注。

# Boundaries

- 不改变已在用的统一域语义：未知值为 `null`、百分比与金额分离、窗口统一为 rolling/weekly/monthly、状态优先级不变。
- 不接管 CPA 的请求转发；sidecar 只读登录、模型、额度三个钩子，不执行插件的 `fetch`。
- 不删除任何既有管理路由；旧工作区作为兼容页签保留，仅删除旧顶层壳层。
- 不引入新的前端框架或组件库；继续 React 18 + Vite + Tailwind。
- 不修改与本任务无关的业务实现（巡检、通知、风险控制、自更新等）。
- 本机缺少 Bun、Playwright 或运行中的 CPA v8 时，如实标注“未验证”，不伪造日志、截图或测试结果。
